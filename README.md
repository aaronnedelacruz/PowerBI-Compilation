# PowerBI Compilation

A collection of Power BI dashboard projects showcasing data visualization, report design, and interactive analytics using real-world datasets.

## Preview

## Dashboards

### Auto Sales Dashboard

An interactive sales dashboard that analyzes automobile sales data across multiple countries, products, and market segments.

**Key Insights**

* Sales performance by country
* Product sales comparison
* Revenue and sales trends
* Interactive filtering and data exploration

### Titanic Dashboard

A dashboard exploring the Titanic passenger dataset through interactive visualizations of demographics and survival statistics.

**Key Insights**

* Survival rates of passengers
* Passenger class distribution
* Country or location of origin
* Gender and age comparisons
* Survival analysis across different passenger groups

## Tech Stack

* Microsoft Power BI
* Google Spreadsheets

## Purpose

This repository serves as a collection of Power BI projects demonstrating dashboard creation, data visualization, and business intelligence reporting using different datasets.
